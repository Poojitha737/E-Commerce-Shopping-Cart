# E-Commerce Shopping Cart

Java console project from the supplied report demonstrating OOP, collections and JDBC/MySQL.

## Requirements
- JDK 8+
- MySQL
- MySQL Connector/J

Run `sql/schema.sql` first. The sample code connects to `ecommerce_db` as `root` with an empty password; change this for your local setup.

The source is kept as one Java file because that is how it appears in the supplied report.
